# How to contribute

Contributions from product, production planning and technology people are welcome. You don't need
to write code. An edge case the contract doesn't cover, a clearer rule or a fix in the documentation
also improve the project.

## Setup

1. Fork the repository and create a small branch.
2. Install Node 22 or later and run `npm install`.
3. Run `npm test`, `npm run typecheck` and `npm run readiness` before and after your change.

## Good contributions

- Explain which problem of planning, the shop floor or IT is being solved.
- Change the contract document and the code in the same pull request.
- Respect the [principles](../vision/principles.md), especially: no made-up numbers on the floor.
- Record relevant decisions in [DECISIONS.md](../DECISIONS.md), with alternatives and accepted cost.
- Use fictional data only.

By taking part, you agree to the [Code of Conduct](../../CODE_OF_CONDUCT.md).
